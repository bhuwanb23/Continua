# Synthetic name source

All patient, provider, and organization names in continua-synth-v1 are fabricated by deterministic template combination of a fixed given-name list and a fixed family-name list, with no lookup against real people, clinicians, or institutions. Provider organizations are invented (`Northlake Primary Care`, `Cedar Ridge Imaging`, `Metro Lab Services`, …). No real DFW health system name is used as a care site.
