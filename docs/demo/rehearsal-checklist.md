1. Reset workflow state (`/demo?reset=1`).
2. Validate cache (`npm run validate:demo-cache`).
3. Check `/health` and `/readiness`.
4. Open `/demo` and warm required routes.
5. Close irrelevant tabs and DevTools.
6. Test audio and screen share at 1280x720 and 1440x900.
7. Run the script twice, targeting 80–85 seconds.
8. Confirm no unsupported factual claims.
