# Judge Machine Checklist

Before the demo:

1. Open the hosted URL or start the local production build.
2. Run `npm run demo:check`.
3. Run `npm run demo:warm`.
4. Confirm no console errors in the flagship path.
5. Confirm the backup video is available.
6. Keep the evaluation page open in a second tab.

Do not debug live. If a check fails, use the recorded backup.
